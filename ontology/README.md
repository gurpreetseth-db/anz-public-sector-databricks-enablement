# Ontology Plan

Use ontology and discoverability to give the audience a clear example of shared public sector language.

## Proposed domains

* Emergency Operations
* Planning and Preparedness
* Recovery and Community Impact

## Candidate glossary terms

* Incident
* Severity Classification
* Response Time
* Containment Status
* Resource Deployment
* Affected Region
* Weather Risk Index
* Priority Queue

## Design notes

* Keep definitions short, plain, and operational.
* Link terms back to curated tables and executive metrics where possible.
* Use ontology to explain why consistent definitions matter across agencies and executive reporting.
