# Genie Plan

The Genie experience should answer practical, command-level questions using curated gold tables.

## User personas

* executive sponsor
* operations lead
* analytics manager

## Example questions

* Which regions have seen the highest incident volume this quarter?
* How have response times changed for high-severity incidents?
* Which resource types are under the most pressure today?
* What weather patterns correlate with escalation risk?

## Design guidance

* keep the space tightly scoped to curated assets
* provide clear instructions so responses stay operational and grounded
* pretest a small set of high-confidence prompts in presentation order
* connect Genie answers back to governed metrics and definitions
